# Random User Viewer

A modern frontend application that fetches and displays random user profiles using a public API. Built to practice real-world API integration, data handling, and clean UI rendering.

Live Demo: [https://random-user-phi-one.vercel.app/](https://random-user-phi-one.vercel.app/)

---

## Overview

The Random User Viewer is a practical frontend project focused on consuming API data and presenting it in a structured, user-friendly interface.

It simulates real-world scenarios where applications need to:

* Fetch user data dynamically
* Display profiles in a clean layout
* Handle loading and error states efficiently

---

## Purpose of This Project

This project is part of a learning assignment from ChaiCode, aimed at understanding how to use FreeAPI in frontend development.

Goal: Learn how to fetch, manage, and display real-time API data in a scalable UI.

---

## Features

* Fetch random user data from API
* Display user profiles (name, image, and details)
* Fast and responsive interface
* Dynamic rendering using JavaScript
* Error handling and fallback UI
* Fully responsive design

---

## Key Learnings

This assignment helped me build strong fundamentals in:

* API Integration: Working with FreeAPI endpoints and understanding response structure
* Asynchronous JavaScript: Using fetch, async/await, and handling promises
* DOM Manipulation: Dynamically updating UI based on API response
* Data Handling: Extracting and structuring nested API data
* Error Handling: Managing failed API requests gracefully
* UI Design Thinking: Creating clean and readable layouts
* Code Organization: Separating HTML, CSS, and JavaScript
* Deployment Skills: Hosting the app using Vercel
